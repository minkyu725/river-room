## 실행

```sh
npm run dev
# http://localhost:4173
npm test
```

2~6인, 새 테이블 시작 시 1,000칩, 10/20 블라인드. 다음 핸드에도 보유 칩을 유지하며 칩이 소진된 상대는 쉬고, 내 칩이 소진되거나 한 명만 남으면 테이블을 종료합니다. 딜러 순환, 체크/콜/폴드/노리밋 레이즈/올인, 사이드 팟을 지원합니다. 매 핸드 종료 시 폴드한 플레이어까지 패를 공개하며 남은 보드를 옅게 공개하고 모든 참가자가 폴드하지 않았을 때의 가상 승자도 표시합니다. 카드·칩·액션 효과음과 음소거를 지원하며 최근 30개 기록을 기기에 저장합니다 (최근 10개를 UI에서 조회).

승률은 자기 패와 공개 보드만 이용하는 몬테카를로 1,800회 추정 에퀴티입니다. 동률의 팟 지분을 포함하며 실제 상대 패나 액션별 레인지 추론은 포함하지 않습니다. Web Worker에서 계산하며 미지원 환경에서는 600회 계산으로 대체합니다.

AI는 자기 패/보드로 110회 샘플링한 에퀴티, 팟 오즈, 성향, 확률적 블러프, 현재 핸드의 내 공격성과 이전 공개 패에 따른 블러프 의심을 이용합니다. 상대의 실제 비공개 카드를 읽지 않습니다. 전문 포커 솔버가 아닌 연습용 휴리스틱입니다. 과거 약한 패의 레이즈를 블러프 신호로 쓰므로 실패한 드로 등과 엄밀히 구분하지 않습니다.

## GitHub Pages 배포

1. GitHub 저장소를 만들고 이 폴더의 파일을 main 브랜치에 푸시합니다.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다.
3. Deploy GitHub Pages 워크플로 완료 후 표시되는 URL을 엽니다.

모든 앱 경로가 상대경로라 `/저장소명/` 주소에서도 동작합니다. 서버/외부 API/비밀 키가 필요하지 않습니다.

iPhone: 배포 URL을 Safari에서 열기 → 공유 → 홈 화면에 추가. 최초 온라인 로드 후 서비스워커 설치가 완료되면 오프라인으로 실행 가능합니다. 버전 변경 시 sw.js의 CACHE 이름을 변경하고 재방문하면 갱신됩니다. 실제 돈/결제/멀티플레이 기능은 없습니다.
